About DocAI

DocAI is a document-based AI system that allows users to upload PDFs, DOCX, or TXT files and ask questions. The chatbot retrieves relevant content using vector embeddings and generates accurate answers using an LLM.

Key Features

Document Upload

Supports PDF, DOCX, and TXT files.

RAG-based AI

Answers are generated only from document content.

Fast & Accurate

Uses vector search and optimized LLM inference.
